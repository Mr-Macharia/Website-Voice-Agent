## Multi-Agent WhatsApp AI Assistant

**What it is:** A WhatsApp assistant that processes incoming chat messages,
runs context-aware reasoning, calls external APIs and search engines, and
executes autonomous scheduled automations.

**Stack:** Agno agentic framework, FastAPI for webhook handling and routing,
PostgreSQL for long-term agent session and memory storage, Evolution API for
WhatsApp gateway connectivity.

**Started:** April 2026, ongoing. Associated with Gich AI Nexus.

## This website and its voice agent

**What it is:** The site you are talking to. A real-time voice and text agent
that answers questions about Gichogu's work, with retrieval over his own
knowledge base, web search, and meeting booking.

**Stack:** LiveKit WebRTC for real-time audio, Deepgram Flux for speech-to-text
and text-to-speech, the Agno framework for the agent, PostgreSQL with pgvector
for retrieval and session memory, Next.js and TypeScript on the frontend.

**Repos:** Website-Voice-Agent, AI-Enginner-Portfolio-Website
